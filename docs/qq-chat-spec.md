# QQ 群内 agent 对话

## 已确认范围

- 指定群内，只有 `QQ_OWNER_ID` 可以通过真正的 @ 消息段触发；主人身份独立于晚报全体成员。
- 普通问答、查询本群已保存消息、读取直接分享的公开网页。pi agent 自主决定工具调用顺序，再生成最终文本。
- 程序负责校验触发条件、限定查询群、限定可读链接、固定回复原群。模型不接触任意群发送、Shell 或写文件工具。
- 按群与主人隔离多轮对话，SQLite 持久化，重启恢复。每次加载最近 12 条对话；不做摘要或更早对话检索。

## 处理边界

- NapCat 使用 `array` 消息格式，按事件 `self_id` 识别机器人的 QQ 号。普通文本伪造 @、@全体、私聊、机器人自身消息不触发。
- 文本段合并为当前请求；仅 @ 时按“你好”处理。图片、语音、卡片和引用正文暂不解析。消息超过 4000 字时提示缩短。
- 主人的 @ 请求同时进入群记录与对话表；机器人自身回复不进入晚报候选。指定群所有成员的消息均可成为晚报候选。
- 查询工具固定当前群，关键词匹配，最多返回最近 50 条记录；记录来源仍受晚报全体成员范围限制。
- 网页工具只读取当前请求、加载的用户对话或本次查询结果中的直接链接，沿用现有公开网页读取限制；不能继续访问网页内链接。
- 请求全局串行，最多 5 个正在处理或排队请求，满队列忽略新请求。单请求最多 8 轮模型调用及配置数量的工具调用，90 秒取消；退出时取消当前请求并停止排队请求。
- 按群号、消息 ID 持久化去重。事件超过 5 分钟不触发，处理中的请求重启后不自动重放；用户重新 @ 可发起新请求。
- 最终回复使用 OneBot 文本段，CQ 字符串按文本发送。单条最多 3500 字，过长截断并提示追问。使用原消息的引用段回复。
- 必须收到匹配 echo 的成功回执才保存 assistant 回答；失败、断线或 15 秒回执超时均不自动重发。回执丢失时 QQ 可能已收到，但本地不声称发送成功。

## 本次开发与验收

- 本次功能：主人在群里 @ 后进入 agent 工具循环并获得原群回复，支持接续对话。
- 必要知识：事件如何通过权限检查进入 agent；工具结果如何返回模型；会话以什么字段隔离。SDK API 可随用随查。
- 助手负责：消息识别、权限、上下文存储、工具限制、OneBot 回执、异常处理、测试及配置说明。
- 软件验收：非主人/非白名单/假 @ 不调用模型；连续请求按序处理；重启保留上下文及去重状态；跨群查询和任意链接被拒；真实 SDK 循环可查询、读链接、回答并在预算耗尽后停止；QQ 失败回执不记为成功。
- 用户验收：主人真实 @ 后收到回答，追问能接续；查询记录与网页时终端出现对应工具名。非主人 @ 不触发。真实模型调用与用户确认单独记录。
- 暂缓：Shell、模型写文件、多 agent、私聊、跨群主动发言、图片和语音理解。

## 最新采集与保留规则（2026-09-24）

指定群所有成员的运行期间新消息都会采集，旧 QQ_AUTHOR_IDS 配置不再生效；仍不补取停机历史、不下载音视频。晚报继续筛选 agent 开发及产品主题，仅主人可 @ 触发对话。

本地群消息、对话、网页缓存、晚报和投递正文最多保留七天。启动时及每分钟清理；过期对话和群消息查询立即排除。派生回答继承已使用来源的最早到期时间，晚报按窗口起点计算七天期限，因此部分派生内容会提前删除。已有对话缺少来源时间，迁移时保守按本会话最早消息计算到期。停机时无法执行清理，下次启动先清理。QQ、Telegram 和模型服务端副本不由本地清理删除。

## 回复风格与长消息

nib 是主人的个人 QQ 助手，默认自然简短：问候只回一句，普通问题 1～3 句话，明确要求详细时再展开。回答超过 100 个 Unicode 字符（含标点、空白，表情按码点计）使用一张合并转发卡片；100 字及以内直接引用回复。合并转发节点署名 nib，使用机器人自身 QQ 号。发送失败不自动降级重复发长文本。

## TinyFish 搜索

配置 TINYFISH_API_KEY 后，主人可 @nib 请求搜索公开信息。web_search 返回最多 5 条标题、链接、摘要，并允许 read_link 读取本次搜索结果链接；摘要不代表已阅读正文。搜索查询会发送给 TinyFish，默认不持久化搜索结果。沿用工具预算、取消和一周对话保留规则。此集成直接使用 SDK，不加载开发助手的 MCP、Shell 或浏览器操作工具。
